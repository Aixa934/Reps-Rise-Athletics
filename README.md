# Reps & Rise Athletics — Student eCommerce Mockup

This is a static website project designed for the eCommerce final project.

## Included features
- Homepage
- About Us
- Product catalog with category filter
- Individual product detail pages with size and color options
- Cart with quantity controls and subtotal
- Simulated checkout (no real payment processing)
- Social media page
- Contact form demonstration (does not send messages)
- Gallery / portfolio
- FAQs, Testimonials, Blog, and Feedback pages
- Responsive desktop and mobile layout

## Important limitations
This is an academic mockup. It does not process payments, transmit orders, send contact messages, calculate shipping/tax, or store inventory in a server database. Never enter real payment information. Social links are generic platform links and should be replaced with official brand profile URLs if created.

## Publish using GitHub Pages
1. Create or sign in to a GitHub account at https://github.com.
2. Create a new repository. Name it `reps-rise-athletics` and set visibility to **Public**.
3. Upload `index.html`, `style.css`, and `script.js` to the repository's top level (not inside a nested folder).
4. Open the repository's **Settings** tab.
5. In the left menu, choose **Pages**.
6. Under Build and deployment, select **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a few minutes. GitHub will show the published URL in the Pages area, typically `https://YOUR-USERNAME.github.io/reps-rise-athletics/`.
9. Open the URL in a private/incognito window to verify it works without signing in.

GitHub's UI may change. If you cannot find a step, check GitHub Pages documentation: https://docs.github.com/en/pages
